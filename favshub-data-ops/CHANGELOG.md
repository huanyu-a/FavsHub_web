# 更新日志

本文件记录 `favshub-data-ops` 技能包的版本变更。

版本号规则：**主版本**表示接口有破坏性变更（旧调用会失败）；**次版本**表示新增能力（向后兼容）；**修订号**表示文案修正与勘误。

技能可自查是否有新版本，见 `SKILL.md` 的「技能自身版本与更新」一节。

---

## [1.2.0] - 2026-09-21

- **新增** 通告分享卡片端点：`GET /api/ai/token-deals/:id/card.png`。
  返回 900×1200 PNG 二进制，三种风格（`magazine` / `neon` / `clay`），
  内容与网页端「分享通告」面板**完全同源**（服务端复用同一份 Canvas 绘制逻辑）。
  此前卡片只能在浏览器里点出来，技能无法产出图片。
- **新增** 响应头 `x-card-style`（生效风格）与 `x-card-cached`（缓存命中状态）。
- **说明** 该端点为 `read` scope；未审核通过的通告仅作者与管理员可取。

## [1.1.0] - 2026-09-21

- **新增** 通告更新端点：`PUT /api/ai/token-deals/:id`（MCP 工具 `update_token_deal`）。
  采用**部分更新**语义 —— 只传要改的字段，未传字段保持原值。
  在此之前更新通告只能「删除后重建」，既不可逆又会丢失投票与评测记录。
- **新增** 技能版本管理：`SKILL.md` frontmatter 增加 `version` 字段，本 `CHANGELOG.md` 记录变更历史。
- **新增** 技能自更新能力：通过站点公开清单 `{BASE}/skills/favshub-data-ops.json`
  一次拿到全部文件的最新正文，无需逐个下载。
- **修正** 通告列表文案：明确 `PUT` 的字段级语义与状态流转规则。
- **强化** 安全红线：新增输出脱敏要求，禁止在回答中出现站点物理部署路径。

## [1.0.0] - 2026-09-17

首个版本，随 FavsHub AI 数据接口一并发布。

- 书签：查询 / 单条或批量新增（≤50）/ 更新 / 删除
- 文件夹：建目录树 / 改名 / 调整层级 / 删除（书签解绑而非删除）
- 提示词：增删改查 / 收藏 / 版本号自增 / 回收站恢复
- 标签：列举 / 新建（同名幂等）/ 删除（仅管理员）
- Token 通告：查询 / 发布 / 删除
- 通用：`dry_run` 预演、删除需 `confirm`、越权一律 404、限频 600 次/分钟
