## 2. 设计目标（可机器验收）

| # | 指标 | 目标值 | 依据 |
|---|---|---|---|
| 1 | 免费额度字号 | **≥ 10% 图宽**（900px 图上 ≥ 90px） | 缩略图 160px 时 ≈16px，一眼可读 |
| 2 | 标题字号 | **≥ 6% 图宽**（≥ 54px）；实测 6.2–7.1% | 缩略图 160px 时 ≈10px，CJK 可读下限 |
| 3 | 信息块数 | **≤ 6** | 缩略图尺度下每多一块都在抢注意力 |
| 4 | 字号阶梯 | **≤ 5 档**，相邻档 ≥ 1.2× | 现状一篇卡里挤了 8.5/9/9.5/10/10.5/11/12 等 9 档，视觉无层级 |
| 5 | 二维码 | 尺寸 **≥ 15% 图宽**，白边静区 **≥ 4 个模块** | 保证扫码成功率 |
| 6 | 安全区 | 额度+标题落在 **1:1 中心裁剪区**内 | 部分平台/OG 卡片按正方形中心裁剪 |

## 3. 美术方向：夜幕鎏金（用户选定）

第一轮「texture/photo」原型被用户驳回（"一点美观度都没有"）——只解决了字号/层级，没做视觉工艺。第二轮做了三个美术方向，用户选定 **A 夜幕鎏金**：

| 方向 | 视觉语言 | 落选原因 |
|---|---|---|
| **A 夜幕鎏金** ✓ | 深紫渐变夜幕 + 鎏金渐变巨号 + 玻璃拟态条 + 证书式金框 | — |
| B 奶油复古票券 | 米黄纸底 + 锯齿撕边 + 印章 | 与现有 voucher 风格语义重叠 |
| C 瑞士极简大字 | 纯白底 + 黑色巨号 + 红色饰带 | 过于冷静，缺分享冲动 |

工艺细节：斜向深紫渐变底 + 品红/紫罗兰双辉光 + 70 颗确定性星点（mulberry32 固定种子）；鎏金细框内缩 14px + 四角加重；数字走 Arial Black 展示字族 + 金→橙→琥珀纵向渐变 + 26px 金辉光；中部描边空心"免"字做纵深。

## 6. 额度文案 → 数字 / 单位 / 说明三级

现状的长额度（线上最长 68 字）在旧默认里被塞进左栏 246px 宽暗色块一行截断。`extractQuotaHero()` 改成：

1. **枚举全部"独立数字 + 量级 + 单位"候选**（支持千分位 `10,000`；紧贴字母/数字/`.`/`-` 的数字视为模型版本号跳过，如 `Qwen2.5-7B`）；
2. **免费档优先**：出现在「充值 / 付费 / 购买」之后的数字是付费档，只要有免费档候选就不做主角（"每日 50 次 / 充值 10 美元后 1000 次"取 50 次）；
3. **同档取换算量级后数值最大者**："15 RPM / 1500 RPD" 取 1500 RPD——速率限制不该盖过日额度；
4. **没有可用数字时**才回落「永久免费 / 永久有效 / 不限总量 / 不限次数 / 无限量 / 不限量」结论词；
5. **原文降级**：仅当原文明显长于主角时，补一行 10px 完整说明（超长省略）。

## 7. 边界降级规则

| 情况 | 处理 |
|---|---|
| 无额度字段 | 主角兜底 `限时免费` |
| 额度 ≤ 3 天到期 | 顶部 5px 金→红渐变紧急带；有效期 pill 转红色描边 |
| 标题超长 | 32 → 30 → 28px 逐级自适应，优先不砍字；3 行放不下才省略号 |
| 服务商超长 | 单行省略号截断，不换行 |
| 无 favicon | 紫底白字首字母方块 |
| 无模型/无实测 | 可信度行退化为"社区众包验真" |
| 额度主角宽度超 | 64px 逐级降到 34px |

| `measure-legibility.mjs` | 扫墨迹块高度（粗筛） |

**两个已踩的坑（复跑时必看）**：
1. `new Image()` + `img.src = Buffer` 是**异步解码**，同一 tick 内 `drawImage` 会静默画出空白 → 必须 `await loadImage(buffer)`；
2. `@napi-rs/canvas` 的 `getImageData(x, y, w, h)` 读**子矩形**会返回全零 → 校验像素要读整张画布再在 JS 里取区域。

**回归出图（5 数据形态 × 6 风格）**：`.workbuddy/tmp/render/out-cur/cur-{full,minimal,longest,soon,forever}-{poster,magazine,neon,clay,blast,voucher}.png`
